# Utvecklingsanalys v0.2.0

Releasekandidat för den samlade informationsmodell v2-analysen.

## Nyheter
- En gemensam analysvy byggd på kanonisk informationsmodell v2; den äldre parallella analysvyn har avvecklats.
- Excelimport med granskning och godkännande, källhantering, UO/LO- och avdelningsanalys.
- Tim- och kostnadsmått, utveckling/förvaltning, årsvisa analyser, UO-grupper, diagram och CSV-export.
- Spårbarhet, antal bidragande källposter, kompletteringar, aktivitetsfördelningar och godkännanden.
- Organisation × år-matris och navigering till kompletteringar.
- Lokal projektbackup och återställning med bevarade historiska data.

## Viktigt
- Gör projektbackup före uppdatering.
- Äldre sparade semantiska data raderas inte, men äldre analysgränssnittet finns inte längre.
- Den fristående HTML-filen körs i webbläsaren med lokalt ursprung (`file://`) och kan ha andra lagrings- och kommunikationsbegränsningar än GitHub Pages.
- Kontrollera releasearbetsflödet och att `utvecklingsanalys-standalone.html` faktiskt bifogats innan versionen markeras som levererad.

## Kontrollpunkter
- CI: lint, typecheck, Vitest, produktionsbygge och single-file-bygge.
- Playwright: importer, källbyte, kompletteringar, mobil layout, projektbackup och kanoniska analysresultat.
- Kontrollera GitHub Pages och fristående HTML efter publicering.

Releasekällan ska vara tagg `v0.2.0` på mergad releaseförberedande `main`, inte en äldre PR-commit.
